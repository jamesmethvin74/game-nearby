# Game Nearby

First-pass prototype for finding nearby high-school and college sports events.

## Included
- Conway, Arkansas default location
- Browser geolocation
- 10/25/50/100-mile radius filtering
- High-school, college, football, and basketball filters
- Followed teams saved in the browser
- Priority display for UCA Bears and Conway Wampus Cats
- Google Maps directions
- Google Calendar links
- Installable PWA shell and offline caching

## Current limitation
The included events are sample data. Production use requires schedule ingestion from official school calendars, athletics sites, feeds, or licensed APIs.
