The resilient Hooten catch-up is intentionally bounded to at most 20 missing finals per run. It deploys the permanent scheduler/finalizer, executes one token-gated forced pass, then performs one combined read-only D1 verification requiring 90/90/0, all ten historically missing Week 1 score rows, Conway 14-Bentonville 20 FINAL, and zero verification writes. The deploy hook is not changed by this branch; production execution is enabled only by a separate temporary hook change after this code is merged.
